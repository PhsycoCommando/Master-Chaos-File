# /scan-project

## Goal
To perform a high-level scan of the workspace, understand the project's purpose, what it does, and generate a comprehensive structural overview report for the user.

## Instructions
1. **Analyze Project Structure**: Use tools to list directories and read key entry point files (e.g., `package.json`, `index.js`, `main.go`, `README.md`, etc.).
2. **Determine Purpose**: Summarize what the application is designed to do based on the discovered files, dependencies, and code patterns.
3. **Generate Report**: Present a detailed report to the user including:
   - **App Name/Identity**: What the project seems to be.
   - **Primary Function**: The core problem it solves.
   - **Tech Stack**: Key languages, frameworks, and libraries.
   - **Architecture Overview**: How the main pieces fit together.
