# Frontend Design Skill

**Core Skill File:** [`SKILL_frontend-design.md`](SKILL_frontend-design.md)

## What is this skill?
This skill forces the AI to step out of its default, boring programming mindset and act as an elite frontend designer. It strictly prohibits generic "AI slop" aesthetics (like system fonts, plain purple gradients, and basic bootstrap-style layouts). Instead, it commands the AI to commit to bold, highly specific design paradigms—whether that's brutalist, luxury/editorial, soft pastel, or maximalist chaos. 

The goal is to deliver production-grade implementation (HTML/CSS/JS or modern frameworks) that relies heavily on unique typography, distinctive spacing, engaging CSS animations, and complex textures to create a "wow" factor.

## When to use it
Trigger this skill whenever the user asks you to:
- Build a new web page, landing page, dashboard, or application UI.
- Create React, Vue, or raw HTML/CSS components.
- "Beautify," "redesign," or upgrade the styling of an existing frontend project.
- Create visual web-based artifacts or posters.

## How to use it
Consult the core skill file before writing any UI code:
1. **Pick a Direction**: Decide on a specific, distinctive vibe (e.g. bold brutalism, sleek luxury minimalism) and stick to it.
2. **Typography is Key**: Ignore boring defaults like Arial, Roboto, or Inter. Import distinctive Google fonts that fit the vibe.
3. **Execution**: Write the necessary code applying generous spacing, hover states, entrance animations (`animation-delay` cascades), and rich background styling (noise filters, gradients, meshes) to produce a true, premium interface.

## Keep or Delete?
- **Keep it if:** You actively build modern web applications, landing pages, or components and want them to be visually stunning, engaging, and premium without needing to explicitly micro-manage the CSS.
- **Delete it if:** You are primarily working on backend code, data engineering, terminal utilities, or internal dashboards where aesthetics are completely irrelevant.
